## How to give feedback

Edit `<video>/feedback.json`. Every frame that was sent is already listed, with
the metrics Tesseract read on it. Fill in:

- `needed`: `true` if the frame carries a number you need that no other sent
  frame has; `false` if it's waste (a chart, the rates list, or a duplicate).
- `note`: optional, anything about that frame.
- `should_have_been_sent`: frames that were **not** sent but should have been.
  Give the frame number from the timeline or from `frames/`, e.g.
  `{"frame": "frame_000321.jpg", "why": "only frame with the Gender split"}`.
- `metrics_missing_from_final_set`: metric names you can see in the video but
  not in any sent frame, e.g. `["gender_men", "gender_women"]`.
- `status`: set to `"done"` when finished; `reviewer`: your name.

What the feedback is for:

- `needed: false` frames become `bad` labels for the next classifier round, and
  test cases for the coverage step.
- `should_have_been_sent` and `metrics_missing_…` are the most serious signal:
  they are metrics the pipeline would have lost. Each one becomes a
  ground-truth entry and a regression test.

The `feedback.json` files and this README are tracked by git; the frames and
pages stay local (see `.gitignore`).
