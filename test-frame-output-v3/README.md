# Frame review v3: after the filter-button fix and the gender fields

Local pre-OCR pipeline only: extract → classify → scroll-aware selection →
metric coverage (Tesseract) → batch. **No OpenRouter call was made.**
Generated by `_generate_review.py` using the app's own modules and the
effective settings in `processing/config.py`. The script refuses to run if
anything overrides those settings or if Tesseract `fas+eng` is missing.

Settings: model `2026-09-19-relabel` at threshold 0.30, `frame_selection=scroll`,
`coverage_selection=true`, every 3rd frame, 720p, batch 12.
Compare with `../test-frame-output/` (v1) and `../test-frame-output-v2/`.
